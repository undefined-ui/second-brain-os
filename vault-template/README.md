# vault-template

A starting vault. Copy this folder somewhere on your machine, open it in
Obsidian as a vault, and start Claude Code inside it.

```bash
cp -r vault-template ~/second-brain
cd ~/second-brain
claude
```

`CLAUDE.md` is the instruction sheet the agent reads every session. Read it
before your first run and edit the parts that do not match how you think. The
default rules are deliberately strict about linking and about never
overwriting a contradiction, because those two are what separate a vault that
compounds from a folder of summaries.
