# Reading

## The pattern

- Karpathy's `llm-wiki` gist (2026-04-04). The spec everything else builds on:
  the LLM maintains the wiki, the wiki is primary, raw sources are archive.

## The tradition it comes from

- **Building a Second Brain**, Tiago Forte. Where the term comes from, and the
  PARA method. Written before agents existed, which is exactly what makes it
  useful to read now: most of the book is about the maintenance work that an
  agent removes.
- **How to Take Smart Notes**, Sönke Ahrens. The Zettelkasten method. The
  argument for atomic notes and dense linking still holds; the manual labour it
  demands is the part that killed it for most people.
- **Andy Matuschak's evergreen notes**. The strongest case for notes written to
  be reread, and a useful counterweight: not everything should be delegated to
  a machine.

## Why the maintenance argument matters

Every note system in the list above works. They fail on the same thing, which
is that the person maintaining them gets tired. That is the entire reason this
pattern is different, and it is worth reading the originals to see how much of
the design was shaped by that constraint.
