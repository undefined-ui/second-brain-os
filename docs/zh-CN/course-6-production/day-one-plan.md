# 第一天行动计划

六个模块的理论，一下子全记住并不容易。因此，这里把整门课程压缩成一个工作日的行动。五层架构，每一层只选一个成本最低、立即见效的动作。它们都不需要新的基础设施，也都可以在你下一次让智能体无人看管地运行之前完成。

<a id="context-make-the-stable-part-byte-stable"></a>

## 上下文：让稳定部分保持字节级稳定

把不同运行之间从不改变的内容——角色、规则、输出格式、工具指南——统一移入一个系统提示词，确保每次逐字节相同。[模块 1](../course-1-context/how-models-read.md)解释了原因：模型对信息位置敏感，会把稳定前缀视为基本规则，而非对话内容。运维上的额外好处是，提示词缓存只对完全相同的前缀生效，因此这一次调整，既能让行为更一致，又能降低每次运行的成本。动态材料——任务、检索到的笔记、工具结果——放在稳定区块之后，绝不要混入其中。关于哪些内容应该进入上下文、应按什么顺序排列的更深入方法，见[运行框架手册的上下文工程篇](../track-harness/context-engineering.md)。

<a id="loop-set-a-turn-limit-and-a-dollar-limit"></a>

## 循环：设置轮次上限和金额上限

在你不盯着智能体运行之前，它需要两个上限：最大轮次数，以及每次运行的最高花费。[模块 2](../course-2-loop/loops-vs-workflows.md)说明，没有停止条件的循环不叫自主，而叫没有边界——它的失败方式并不惊天动地，只是智能体客客气气地重试一个坏掉的工具四十次，费用由你承担。两个上限都只需几行代码，触及任意一个都应明确报出原因、结束运行并保存轨迹，让每次被截断的运行都能带来经验。停止条件、评审器和通宵运行，是[循环工程手册](../track-loop/README.md)的主题。

<a id="gate-label-200-examples-of-your-most-common-decision"></a>

## 决策关卡：为最常见的决策标注 200 个样本

找出系统最频繁做出的一个决策——保留还是丢弃、转发到 A 还是 B、是否值得标记——并亲自标注 200 个真实样本。[模块 3](../course-3-gate/cheap-decisions.md)指出，智能体的大部分调用根本不是生成，而是分类；一个标注集能够把流水线中最模糊的部分变成可测量的部分：现在你知道负责该决策的方案准确率如何，也能换成更便宜的方案，并证明没有破坏原有表现。全部成本不过是一个下午的标注。[Jev 工程手册](../track-jev/README.md)深入介绍带置信分数、具有明确类型的决策。

<a id="harness-run-the-agent-as-a-user-that-cannot-delete-anything"></a>

## 运行框架：让智能体以无法删除任何内容的用户身份运行

为智能体创建单独的账号或角色，赋予读取权限和对自身工作空间的写入权限，但不给删除、付款和管理员权限——今天就让它以这个身份运行。[模块 4](../course-4-harness/the-office.md)把运行框架比作智能体的工作环境；这是成本最低的版本，可以把一整类灾难性失败变成你在日志中看到的权限错误。它还让审计问题变得简单：这个账号做的任何事，都是智能体做的。防护措施、工具策略，以及如何逐步授予更大权限，见[运行框架手册](../track-harness/README.md)。

<a id="evals-write-the-last-five-failures-down-as-test-cases"></a>

## 评估：将最近五次失败写成测试案例

回想智能体最近五次做错的事——你还记得它们——把每一次都变成测试案例：输入是什么，正确输出必须包含什么。[模块 5](../course-5-evals/two-kinds-of-checks.md)介绍了两类检查；五个回归案例是最朴素的测试套件，但已经足以为下一次提示词变更把关。从这里开始，飞轮就会自行运转：每个新失败都变成一个案例，测试套件正好在系统最薄弱的地方不断增长。完整方法见[评估工程手册](../track-evals/README.md)。

<a id="the-hard-part-moved"></a>

## 难点已经转移

最后坦诚说一句：模型已经不再是最难的部分。它拿来就很有能力，不需要你帮助也会进步，而且每年都更便宜。演示与可信赖系统之间的区别，来自它周围的一切——它读取什么、何时停止、怎样决策、被允许接触什么，以及你如何确认它仍在正常工作。这就是五层架构。它们并不光鲜，大部分只是基础管道，但如今真正的工作就在这里。
