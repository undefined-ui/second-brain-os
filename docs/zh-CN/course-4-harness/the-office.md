# 工作环境

即便雇用了世界上最聪明的工程师，把他放进糟糕的工作环境——没有所需房间的钥匙、没有文档、没有测试套件，再配上一个不看内容就批准一切的经理——得到的也会是糟糕的工作成果。智能体等于模型加运行框架：模型是你雇用的人，运行框架则是工作环境。[什么是运行框架](../track-harness/what-a-harness-is.md)介绍其组成——循环、工具、提示词、权限、上下文。本模块讨论的是构建方法：工作环境本身就是需要设计和测量的产品，并非聪明核心之外的一层包装。

<a id="you-buy-a-model-and-a-harness"></a>

## 你买的是模型和运行框架

没有人直接运行一个裸模型。一旦采用 Claude Code、LangChain 的 deepagents，或自己写的七十行循环，你就选择了第二个产品，它也有自己的质量曲线。供应商按 token 为模型定价，却免费提供运行框架，这很容易让团队以为，既然免费，就不重要。2026 年的测量结果恰恰相反：只改变工作环境，基准分数的变化就能超过前沿模型之间的差距。

<a id="six-points-from-container-resources"></a>

## 容器资源带来六个百分点

2026 年 3 月，Anthropic 在 Kubernetes 集群上用六种资源配置重新运行 Terminal-Bench 2.0：从严格执行每项任务的 CPU 和内存规格，到完全不设上限——模型相同、运行框架相同、任务也相同。资源最多和最少的配置之间相差 6 个百分点（p < 0.01）；在严格限制资源时，5.8% 的任务因基础设施错误而失败——容器被短暂的内存峰值终止，而不是模型答错了。详见[量化智能体编程评估中的基础设施噪声](https://www.anthropic.com/engineering/infrastructure-noise)。如果仅仅内存上限就值六个百分点，环境就绝不是细枝末节。它本身就是成绩的一部分。

<a id="thirteen-points-from-the-harness-alone"></a>

## 仅运行框架就带来十三个百分点

2026 年 2 月，LangChain 完全固定模型——全程使用 GPT-5.2-Codex——只迭代 deepagents-cli 的运行框架：系统提示词结构、工具设计，以及循环检测、完成前检查清单等中间件。智能体在 Terminal-Bench 2.0 上的成绩从 52.8 提高到 66.5，未经任何训练就增加了 13.7 个百分点。文章见[通过运行框架工程改进 Deep Agents](https://www.langchain.com/blog/improving-deep-agents-with-harness-engineering)。十三个百分点，比大多数模型代际升级在同一基准上带来的提升还大。

<a id="a-cheaper-model-in-a-better-office"></a>

## 更好的环境，配更便宜的模型

2026 年 7 月的后续文章[调优运行框架，而非模型](https://www.langchain.com/blog/tuning-the-harness-not-the-model-a-nemotron-3-ultra-playbook)，将同样的方法用于 NVIDIA 的开放权重模型 Nemotron 3 Ultra。仅调优运行框架，它在 LangChain 的 Deep Agents 套件中单次最佳成绩就达到了 0.86，而 Claude Opus 4.8 的最佳成绩为 0.87——每次运行成本却约为 4.48 美元，对方为 43.48 美元，大约只有十分之一。这只是一个测试套件，而且评分者正是运行框架的作者，因此不宜过度解读；但趋势与今年其他测量结果一致。好的工作环境，能让成本更低的人选完成工作。

<a id="when-you-need-one"></a>

## 什么时候需要运行框架

智能体接触任何真实事物的那一刻就需要。聊天机器人回答得不好，你皱皱眉头、重试一次就行；在你根据文本采取行动之前，什么都没有发生。拥有 shell、数据库连接或发送按钮的智能体，则会根据自己的输出采取行动——错误答案如今会变成一次已推送的提交、一张已删除的表、一封已发出的邮件。这就是分界线：输出仍是由你审阅的文本时，尽管尝试提示词，不必拘泥形式。一旦输出变成会直接发生的操作，你就需要围墙、指南、传感器和关卡——按这个顺序来。[四层防护](the-four-rings.md)介绍这个构建顺序，[运行框架实践](harness-practice.md)则从头到尾演示如何加固一个真实智能体。
