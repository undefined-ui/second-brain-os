# 第二大脑究竟是什么

一个由智能体读写的本地纯文本文件夹，存放你读过、理解过的内容，并且可以向它提问。

这就是完整定义。本指南的其他内容，都是让它真正运作起来的细节。

<a id="what-it-is-not"></a>

## 它不是什么

**不是更漂亮的笔记应用。** 重点不是整理。你可以把笔记整理得十分漂亮，却再也不打开它们。

**不是附上 PDF 的聊天机器人。** 将文档附加到聊天中，只能让你在当前会话里得到关于这些文档的答案。知识不会积累，内容不会关联，下周你还得再次上传。

**不是记忆功能。** 能记住你的情况的助手很有用，但那是另一回事。这里说的是由你拥有、寿命长于任何特定工具的知识体系。

<a id="the-three-jobs"></a>

## 三项工作

**采集。** 你阅读、观看和记录的一切，以近乎零阻力的方式进入同一个地方。如果采集很费力，其他事情就都没有意义，因为根本没有内容可供整理。

**关联。** 将新资料链接到已有内容中。这是人类在两周后就会停止做的工作，也是此前笔记系统失败的原因。它同时也是全部价值所在：没有关联的笔记，只是一个文件夹。

**回答。** 你可以同时针对所有内容提问，得到基于自己来源的答案，并附有可以打开的引用。

<a id="where-the-value-comes-from"></a>

## 价值从哪里来

不是来自任何单独页面。一个页面，只是比你自己可能写下的笔记稍好一些。

价值来自密度。积累到五十份来源时，知识库开始关联你相隔数月读到的内容。达到五百份时，它能回答你无法独自回答的问题，因为没有人能同时把五百份来源都装在脑子里。

这就是为什么前两周令人感觉平淡，也解释了为什么大多数人在回报出现前就退出了。只有三十个页面时，系统并没有坏，只是还处于早期。有关切合实际的时间线，请参阅[良好运行的样子](what-good-looks-like.md)。
