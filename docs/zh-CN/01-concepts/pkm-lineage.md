# 卡片笔记法、PARA 与常青笔记

这些想法都不新鲜。人们曾经放弃的方法，大体上是正确的。值得了解哪些部分仍然适用，因为那些好想法原本附带的成本，如今已经改变。

<a id="zettelkasten"></a>

## 卡片笔记法

这是 Niklas Luhmann 的卡片盒方法，Sönke Ahrens 在《如何做聪明笔记》中将其推广给现代读者：笔记保持原子化，每条只讲一个想法，密集交叉引用，并用自己的话书写。

**仍然正确的部分：** 原子化笔记、密集链接，以及用自己的话改写而非摘抄引文。这三点都包含在本指南的[组织结构规则](../04-structuring/README.md)中。

**代价：** 每个链接都需要手动建立。阅读一篇论文后，要判断它与几百条已有笔记中的哪些内容相关。这需要真正的认知劳动，也是大多数卡片盒在第三个月就停止维护的原因。

<a id="para"></a>

## PARA

Tiago Forte 在《打造第二大脑》中提出的系统：项目（Projects）、领域（Areas）、资源（Resources）和归档（Archive）。按可行动性，而不是按主题组织内容。

**仍然正确的部分：** 项目资料和参考资料需要不同结构的认识。这与[两个层次](two-layers.md)完全一致，只是从不同方向得出了同样的结论。

**代价：** 你需要不断决定资料该放到哪里；而可行动性又会变化，所以同一条笔记会随时间在不同类别之间移动。

<a id="evergreen-notes"></a>

## 常青笔记

Andy Matuschak 的方法：以概念为中心、密集关联、逐步发展，把笔记写成可在多年间反复阅读和完善的内容。

**仍然正确的部分：** 它定义了优质概念页面的标准。Matuschak 主张，笔记应写给未来的自己，而不是用来证明自己读过什么；这正是本指南对概念页面的要求。

**需要权衡的观点：** 他认为书写本身就是思考，委托别人书写，也就意味着没有亲自思考。这是对整套方法的实质性异议，值得认真考虑，而不应轻易排除。

<a id="what-changed"></a>

## 什么发生了变化

只有一件事：维护工作现在可以委托出去。

上面每种系统都能奏效，也都因同一个原因失败：它们要求人类永远承担枯燥的链接工作。执行这项工作的智能体，不会在第三个月感到疲倦。

<a id="what-did-not-change"></a>

## 什么没有改变

你仍然需要选择读什么，仍然需要判断什么重要。智能体负责归档和关联，但它没有品味；如果你不加选择地投喂资料，得到的只是整理得很好的杂物堆。

Matuschak 的异议也依然成立：理解来自书写。保留这一点的方法是，亲自撰写对你重要的概念页面，让智能体处理来源页面、实体页面和链接。这种分工属于个人偏好，本指南不会强制规定；但你应当有意识地作出选择，而不是任由默认做法决定。
