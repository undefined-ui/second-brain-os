# 良好运行的样子

下面给出具体标准，让你能够判断自己的系统是否有效，而不必猜测。

<a id="the-test"></a>

## 测试方法

问它一个你隐约记得几个月前读过、却无法准确说出名称的问题。

如果它返回那个想法、对应来源，以及两件你已经忘记的相关内容，系统就有效。如果它什么也找不到，或者只给出任何模型都能生成的一般性解释，那就没有奏效。

<a id="signals-of-health"></a>

## 健康信号

**你会先打开它，再搜索网络。** 这是最有力的信号。当知识库足够密集时，这种习惯会自然形成。

**答案引用了可以打开的页面，**而页面中的内容与答案相符。

**图谱出现了你并未规划的聚类。** 这表明它在追踪你实际关注的事物，而不只是你曾经要求它关注的事物。

**新资料主要用于更新现有页面，**而不是创建新页面。这意味着知识库已经具备相应概念，正在加深理解，而不是无序扩张。

**它偶尔会反驳你，**因为你保存了关于某件事的不同立场。

<a id="signals-of-trouble"></a>

## 问题信号

**孤立页面比例上升。** 资料导入过程中已经停止建立链接。请参阅[指标](../05-graphs/metrics.md)。

**页面读起来像摘要，**而不是解释。你需要收紧 `CLAUDE.md` 中的页面规范。

**新来源持续进入，概念页面却几个月没有更新。** 新资料落到了新页面里，而不是更新现有页面，结果就是同一件事出现四个页面。

**你已经不再打开它。** 这是最诚实的信号。通常意味着采集环节坏了，而不是整个想法失败了。

<a id="a-realistic-timeline"></a>

## 切合实际的时间线

**第一周。** 完成搭建，导入十到二十份来源。感觉只是一个操作更繁琐的文件夹。这很正常，也是大多数人放弃的阶段。

**第二到第四周。** 五十到一百份来源。知识库第一次把你相隔几周读到的两件事联系起来。从此，搭建它开始显得值得。

**第三个月。** 几百个页面。它回答问题的速度比你重新阅读更快，还会呈现你已经忘记收藏过的内容。

**第六个月。** 它知道一些你已经不记得自己学过的东西。这就是人人描述的回报，它确实存在，但需要你持续投喂六个月。
