# 内容组织

这些规则决定你的知识库会成为一张关系图谱，还是一座信息垃圾场。

资料导入决定哪些内容进入知识库，内容组织决定能否再次找到它们。即便存放着相同的一千份来源资料，两个知识库也可能一个成为研究伙伴，另一个成为无法检索的资料堆，区别完全在于下面这些规则。

这里的所有规则都应该写进 `CLAUDE.md`：智能体在聊天中读过一次的规则只能维持一个会话，而写在 `CLAUDE.md` 中的规则会约束它今后编写的每一个页面。
