# 图谱

这是大多数第二大脑指南略过的部分。它们只让你打开图谱视图，说一句“看起来像个大脑”，然后就继续往下了。

图谱不是装饰。正是这种数据结构，让 wiki 能回答搜索索引无法回答的问题。它有可以衡量的属性、可以识别的失败形态，也有远不止观赏的用途。

本节介绍图谱究竟有什么用、如何解读、怎样让链接承载含义，以及何时应该将其中一部分迁移到比 Markdown 更强大的工具中。
