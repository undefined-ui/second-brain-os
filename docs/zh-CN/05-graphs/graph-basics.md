# 知识库的图谱基础

无论你是否有意规划，知识库都是一张图。页面是节点，wikilink 是边。上一节中每一项结构决策，实际上都在决定这张图的形态。

掌握四个术语，就足以分析它。本节关注知识库自身的图谱——wikilink、形态和健康状况。关于图谱作为智能体记忆的一般用法，包括 GraphRAG、信息抽取和存储，请参阅[知识图谱手册](../track-graph/why-graphs.md)。

**度**是一个页面拥有的链接数。入度是指向它的链接数，出度是它指向其他页面的链接数。入度为零的页面无法通过沿链接浏览到达，因此孤立页面是实际问题，而不只是外观问题。

**路径长度**是两个页面之间需要经过的跳数。这是影响回答的关键指标：智能体从起始页面沿链接探索，在上下文预算耗尽前只能到达几跳之内的内容。两个相关想法如果相隔八跳，就永远不会在同一个回答中建立联系。

**聚类程度**衡量一个页面的相邻页面彼此链接的紧密程度。聚类程度高，说明这里形成了真正的主题领域。聚类程度低但度很高，通常意味着这个页面只是收集了互不相关的东西。

**连通分量**是彼此断开的孤岛。拥有五个连通分量的知识库，相当于五个独立知识库，其中一个分量里的内容永远无法为另一个分量相关的问题提供信息。

<a id="the-shapes-that-go-wrong"></a>

## 容易出问题的形态

**星形。** 所有内容都链接到两三个枢纽页面，除此之外没有其他链接。任意两个叶节点之间的路径虽然短，却只能经过枢纽，所以这张图除了“它们都在我的知识库里”之外，什么也没有告诉你。通常是因为链接指向了宽泛概念，而不是具体概念。

**链形。** 来源只链接到自己引入的概念，没有横向链接。这在未检查现有页面就执行的批量导入之后很常见。知识库不断变大，却始终无法连通。

**孤岛。** 不同主题簇之间没有桥梁。有时这很合理：烹饪笔记与数据库笔记确实没有联系。但很多时候并非如此：两个有关相近事物的簇使用了不同词汇，又因为缺少别名而始终没有连接。

<a id="what-a-healthy-graph-looks-like"></a>

## 健康图谱的样子

主题内部连接密集，主题之间连接稀疏但确实存在。大多数页面都能在三到四跳内到达其他大多数页面。存在枢纽，但枢纽不会主导整张图。少量桥梁页面连接不同簇，它们通常是最有价值的页面，因为其中包含了仅凭一个来源无法建立的联系。

<a id="why-any-of-this-matters"></a>

## 这些为什么重要

当你向知识库提问时，智能体从匹配的页面出发，向外探索。图谱就是搜索空间。形态良好的图谱让探索在几跳之内就能触达相关材料；形态糟糕的图谱则会让它要么什么都找不到，要么把所有东西都找出来。

这就是制定链接规则的全部理由。它们关乎检索是否有效，而不仅仅是整洁。
