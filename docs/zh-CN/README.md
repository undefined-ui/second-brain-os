## 第二大脑

一个实践项目：让智能体使用纯 Markdown 为你构建并维护知识库。十个章节按照实际搭建的顺序排列：理解模式、搭好系统、导入资料、组织结构、用好图谱、实现自动化、查询知识、产出成果、持续维护，并在出问题时修复。[路线图](../ROADMAP.md)汇总了全部文章，也是在新增文章前提出建议的地方。

| 章节 | 内容 |
|---|---|
| [基本概念](01-concepts/README.md) | 模式的含义，以及传统笔记系统失效的原因 |
| [搭建](02-setup/README.md) | Obsidian、Claude Code、CLAUDE.md、MCP、项目与 git |
| [资料导入](03-ingestion/README.md) | 文章、视频、PDF、聊天记录导出、语音与历史资料回填 |
| [组织结构](04-structuring/README.md) | 页面类型、链接规则、结构规范与矛盾处理 |
| [图谱](05-graphs/README.md) | 图谱的用途、带类型的链接、GraphRAG 与指标 |
| [智能体](06-agents/README.md) | 角色、定时任务、钩子与防护措施 |
| [检索](07-retrieval/README.md) | 查询模式、搜索与上下文预算 |
| [知识输出](08-outputs/README.md) | 写作、报告、发布与学习 |
| [维护](09-maintenance/README.md) | 结构检查、复盘节奏、git、隐私与规模扩展 |
| [故障排查](10-troubleshooting/README.md) | 常见故障及其解决办法 |
