# System One 模型

如今，大多数 AI 产品都建立在大语言模型之上：你输入文本，模型再逐个 token 地写出文本回复。但如果软件真正需要的只是一个决策，这种方式就显得慢且昂贵。“System One 模型”是一个新类别——TypeSafe AI 于 2026 年 9 月 15 日发布名为 Jev 的模型时提出——专门填补这个缺口：用快速、具有明确类型的决策，替代缓慢的文本生成。

本主题对应的课程内容是[模块 3：廉价决策](../course-3-gate/cheap-decisions.md)——介绍这类模型通常服务的决策关卡模式。

<a id="the-kahneman-framing"></a>

## 卡尼曼的理论框架

这个名字借鉴了丹尼尔·卡尼曼的《思考，快与慢》。系统 1 是快速、直觉式的判断；系统 2 是缓慢、审慎的推理。在这一框架下，LLM 是系统 2 机器：它们用文字把推理过程说出来。TypeSafe 的主张是，软件交给模型的大量工作——分类、路由、评分、把关——其实属于系统 1 工作，为此承担 LLM 的延迟和费用是一种浪费。其创始人 Diogo Almeida（曾任职 OpenAI，参与 RLHF 和 ChatGPT 工作）将其称为“具有前沿智能的函数调用：输入非结构化状态，输出带类型的概率性决策”。

<a id="what-jev-actually-returns"></a>

## Jev 实际返回什么

Jev 是非自回归模型：它根本不生成文本。你发送一个 `state`（字符串、JSON 对象或文本数组），再加上一个或多个带类型的问题，它会在一次并行处理中回答全部问题。共有三种基本类型：

- `Choice`——从最多 255 个预定义选项中选择一个，并提供每个选项的概率
- `Score`——将输入放到包含 2–10 个等级的有序量表上
- `Noul`——是/否判断，以 0 到 1 之间的概率返回

每个答案都带有经过校准的概率。TypeSafe 使用其称为 RLCD（面向校准决策的强化学习）的方法进行训练，优化目标是诚实表达置信程度，而非讨好人工评分者。

<a id="honest-caveats"></a>

## 需要坦诚说明的局限

它才发布几天，几乎所有数字都来自供应商自己：

- 最醒目的宣传——比前沿 LLM 大约快 200 倍、最高便宜 400 倍——来自 TypeSafe 团队自己构建的基准测试，公司也承认这些属于偏高的结果。
- “零幻觉”真正指的是零*模式之外*的输出。Jev 不会凭空创造你未定义的选项，但仍可能选错。
- 架构、模型规模和权重均未公开，也还没有经过同行评审的论文。正如 Anthony Maio 等质疑者指出的那样，分布偏移下的校准能力尚未得到证明。

在独立评估出现之前，可以认为机制是真实的，但应将幅度数字视为营销说法。它可能适合哪些任务，见 [Jev 擅长什么](what-jev-is-good-for.md)；想尝试，见[入门](getting-started.md)；来源见[资源](resources.md)。
