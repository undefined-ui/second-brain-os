# 智能体

把一次性的配置，变成能够自行维护的系统。

到目前为止，所有工作你都可以慢慢手工完成。从本节开始，知识库将不再依赖你的自律，而这正是它六个月后仍能保持活力的唯一原因。

风险也在这里。一个拥有笔记写入权限、在你睡觉时按计划运行的智能体，听起来有多有用，就同样有多危险。在安排任何定时任务之前，先阅读[安全护栏](safety-and-guardrails.md)。
