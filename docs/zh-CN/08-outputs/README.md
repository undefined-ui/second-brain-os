# 知识输出

当知识库开始产生输出，它才真正证明了自己的价值。

一个只回答问题的知识库，不过是你亲手编写的参考书。只有当文章、报告、决策和理解从另一端产出，而且你的成品也重新进入知识库时，投入才开始得到回报。
