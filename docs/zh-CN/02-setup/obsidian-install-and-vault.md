# Obsidian 与你的第一个知识库

Obsidian 是系统中负责存储的那一半。它免费，将一切作为纯文本文件保存在你自己的设备上，并将笔记间的链接呈现为图谱。这里的内容不存储在某家公司的云端；即使你不再使用这款应用，文件仍可由任何文本编辑器阅读。

<a id="install"></a>

## 安装

从 [obsidian.md](https://obsidian.md) 下载并安装。

如果你已经执行过 [README](../../../README.md) 中的快速入门步骤，就已经有了包含初始结构的 `~/brain` 文件夹。在欢迎界面点击 **打开文件夹作为知识库（Open folder as vault）**，选择它。

如果从零开始，则点击 **创建新知识库（Create new vault）**。取一个便于经常输入的短名称，`brain` 就可以。选择设备上的文件夹并点击 **创建（Create）**，然后将 [`vault-template/`](../../../vault-template/) 中的内容复制进去。

无论哪种方式，这个文件夹现在都是你的第二大脑。智能体撰写的一切都会以 Markdown 文件的形式保存在这里。

<a id="make-one-note-by-hand"></a>

## 手动创建一条笔记

在自动化任何工作之前，先亲手做一次，让这套机制变得具体可感。

点击新建笔记图标，输入一句话，然后输入 `[[goals]]`。括号里的词会变成指向 `goals` 页面的链接，不论这个页面是否已经存在。点击它，Obsidian 就会创建该页面。

这就是整个数据模型：笔记指向笔记。智能体之后做的一切，都是将这项工作扩大规模，并替你完成。

<a id="where-to-put-the-vault"></a>

## 知识库放在哪里

放在路径稳定、能方便地从终端输入的位置。避免选择会被云同步客户端频繁改写的文件夹，因为同步客户端与智能体同时改写文件，会产生非常难以整理的冲突副本。可行方案见 [Git 与同步](git-and-sync.md)。

文件夹名称不要包含空格。你会把这个路径粘贴到命令中。

<a id="settings-worth-changing-now"></a>

## 现在值得调整的设置

- **文件与链接 → 新建链接格式：** 统一选择相对路径或最短路径。混用链接格式，是重命名后链接损坏最常见的原因。
- **文件与链接 → 自动更新内部链接：** 开启。
- **编辑器 → 显示 frontmatter：** 开启。至少在最初几周，你应该能看到智能体写入的元数据。
