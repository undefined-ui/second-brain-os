# 常见问题

**我需要 MCP 吗？**

不需要。在知识库文件夹内启动的 Claude Code 可以直接读写文件。MCP 增加的是让不在知识库目录中运行的会话也能访问它的能力，这主要对定时任务重要。参见 [Obsidian 的 MCP](../02-setup/mcp-obsidian.md)。

**除了 Claude Code，其他智能体也能用吗？**

可以。知识库是 Markdown 文件，技能是多种智能体都能读取的 `SKILL.md` 文件。任何能够读写文件夹中文件的工具，都可以维护知识库；换用其他工具时，可能需要调整 `CLAUDE.md` 的文件名。

**运行成本有多高？**

完全取决于工作量。每天导入几篇文章，成本不大；一次性补录一千份来源则不然。这正是[批量补录](../03-ingestion/bulk-backfill.md)一节坚持要求分批处理、让成本可见的原因。

**可以使用本地模型吗？**

可以用于敏感材料的导入，但质量会降低。本地模型在这里重要的判断任务上较弱：什么值得单独成页、两个来源何时确实互相矛盾。一种可行分工是，私人材料用本地模型，其他内容用前沿模型。

**我需要 Obsidian 吗？**

不需要。知识库只是一个 Markdown 文件夹。Obsidian 是不错的图谱查看器，还提供 Web Clipper，后者是使用它最有力的实际理由。Logseq、Foam 或普通编辑器也都可以。

**如果我已经在 Notion 或 Evernote 中存了很多笔记呢？**

使用官方 [Importer](https://github.com/obsidianmd/obsidian-importer) 插件，它支持 Notion、Evernote、Roam、Bear 和 Apple Notes。随后把结果当作原始资料，从最旧的开始补录。导出内容很可能比较杂乱，应该先修复提取结果，再做导入，不要指望智能体勉强应付。

**这与记忆功能有什么不同？**

记忆功能在跨会话时记住关于你的事实，属于工具本身。这里则是一套以文件形式由你拥有的知识，生命周期长于任何工具，而且你可以自行阅读、编辑和发布。

**智能体会编造内容吗？**

会有这种可能，因此[组织结构](../04-structuring/README.md)中的每一条规则都在强调归属：把论断作为论断记录，附上来源，指出缺口而非自行补齐。尤其要留意那些具体数字背后没有来源的页面。

**图谱视图真的有用，还是只是好看？**

全局视图主要是好看。局部图谱则确实有用，可以在五秒内检查任何页面的质量。参见[阅读图谱视图](../05-graphs/obsidian-graph-view.md)。

**多久才能值得这些投入？**

第二到第四周会出现第一批真正的回报；到第六个月，通常能进入人们所说的“这才是它的意义”的状态。
