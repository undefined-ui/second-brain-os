# 资料导入

尽量低阻力地把你阅读、观看和书写的一切收进 `raw/`，然后导入 wiki，同时避免让它被内容淹没。

采集环节决定知识库能否持续存在。从看到某样东西到保存下来之间，每多一步，就多一个让你放弃的机会。因此，目标始终是同一个：一次点击或一条命令。

后半部分同样重要：投喂的内容决定了知识库的上限。一百篇剪藏的清单文章，只会产生一百个单薄页面和一张毫无洞见的图谱。
