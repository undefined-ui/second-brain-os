# Graphs

The part most second-brain guides skip. They tell you to open the graph view,
say it looks like a brain, and move on.

The graph is not decoration. It is the data structure that makes a wiki answer
questions a search index cannot, and it has properties you can measure, failure
shapes you can recognise, and uses beyond looking at it.

This section covers what the graph is actually for, how to read it, how to make
links carry meaning, and when to move part of it into something more capable
than markdown.
