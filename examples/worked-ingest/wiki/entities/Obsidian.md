# Obsidian

## What it is

A desktop application for reading and editing a folder of markdown files as a linked vault, with a graph view of the links between pages and a plugin ecosystem. Everything said about it here comes from [[LLM Wiki (Karpathy)]].

## Why it appears here

In the [[LLM wiki]] pattern Obsidian is the owner's window onto the wiki: the source's phrase is that Obsidian is the IDE, the LLM is the programmer, and the wiki is the codebase. The source relies on several of its features. The graph view shows which pages are hubs and which are orphans. [[Obsidian Web Clipper]] turns web articles into markdown for the raw folder. The attachment-folder setting plus the "Download attachments for current file" command pull images to local disk so the agent can view them. The [[Marp]] plugin renders slide decks from markdown and the [[Dataview]] plugin queries page frontmatter. This vault is read in Obsidian, which is why its pages carry frontmatter and wikilinks.
