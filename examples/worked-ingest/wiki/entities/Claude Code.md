# Claude Code

## What it is

An LLM coding agent that works from the command line inside a folder and reads a CLAUDE.md file for standing instructions. It is one of the agents that [[LLM Wiki (Karpathy)]] says the idea file is meant to be pasted into, alongside OpenAI Codex and OpenCode.

## Why it appears here

In the [[LLM wiki]] pattern the agent is the programmer that writes and maintains the wiki, and the schema document that disciplines it is CLAUDE.md for Claude Code (or AGENTS.md for Codex). This vault runs on Claude Code: its CLAUDE.md is the schema the source describes, and the ingest, query and lint operations are its commands and skills.
