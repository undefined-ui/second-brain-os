## Concepts

- [[LLM wiki]]: an LLM agent builds and maintains a linked markdown wiki over an immutable source folder, guided by a schema file; the pattern this vault implements. 1 source.
- [[Retrieval-augmented generation]]: retrieving document chunks at query time and generating from them; the baseline the LLM wiki departs from because nothing accumulates. 1 source.
- [[Memex]]: Vannevar Bush's 1945 curated knowledge store with associative trails; cited as the LLM wiki's ancestor. 1 source.
